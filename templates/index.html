Welcome to NAM Mixer

This blends two NAM amp captures into one sound, then trains a fresh model on the result. Everything below is free to try -- nothing is trained or downloaded until you explicitly ask for it.

  1. Choose two amps -- pick your Amp A/Amp B .nam files above.
  2. Render & audition -- hear the blend live before committing to anything.
  3. Create training files -- once you're happy with the sound, turn it into a training bundle.
  4. Train it -- Kaggle GPU is free and needs no download, just a Kaggle sign-in; local training is the alternative but is a real ~1.4 GB one-time download.

Check Settings any time for exactly what each feature needs and why -- every optional download is explained there before you commit to it.

Advanced: NAM input calibration
Auto compensates for each model's own recording calibration (input_level_dbu) so two differently-captured NAMs see the same virtual input level -- only when BOTH models provide it, otherwise raw digital level is used for both.
The virtual analogue level assumed to correspond to digital full scale (NAM plugin default: +12 dBu). Not a pickup output value.

+0.0 dB
Independent per-amp trim applied BEFORE NAM inference, on top of calibration -- unlike the crossover blend, which only chooses which amp's already-rendered output dominates, this actually changes what each amp receives. Use it when the amp on the "loud" side of the crossfade has too little headroom to stay clean at the levels that select it (or vice versa). Applied to real A2 generation too, not just preview.

Usually a few seconds to under a minute -- real NAM inference on both amps, scales with the DI's length.

Hear the finished model on musical material

            
Renders the frozen teacher target and the actual exported Full/Lite NAM on a held-out test performance (not the training material) and lets you A/B them at real playback level, plus reports ESR/RMS/peak differences between each export and the teacher. "Quiet playing" re-runs the same comparison at -24 dB input to catch a model that only sounds right when played hard.
