# v0.5.3: accessibility improvements

This release improves keyboard and screen-reader access to the Builder and Continuous Gain workflows.

- Skip repeated navigation and move directly to the current work area.
- The welcome guide takes keyboard focus when it opens and returns focus when dismissed.
- Amp A and Amp B file inputs have explicit names; the cabinet picker works as a keyboard-operable button.
- App-wide messages expose status and errors to assistive technology.
- Continuous Gain uses a native, visible file picker and names each capture's gain-position and remove controls.
- The selected Continuous Gain step is exposed to assistive technology, and focus is restored after its content refreshes.

This is an initial accessibility update, not a declaration of full screen-reader compatibility. In particular, plotted measurements still need structured text tables, and the complete workflow needs NVDA and VoiceOver testing. See [the accessibility review](../accessibility_review.md) for follow-up work.
