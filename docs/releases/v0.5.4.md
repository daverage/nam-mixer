# v0.5.4: more keyboard and screen-reader improvements

- Continuous Gain's measurement and input-gain charts now have expandable data tables with exact values.
- Keyboard navigation moves to the active heading after a Builder step or utility change; blocked steps give a spoken reason.
- Sliders with displayed values expose the same units and proportions to assistive technology. Training choices have proper group legends.
- Frequent elapsed-time updates and raw training logs no longer flood live announcements. Training stage changes and errors are announced concisely.
- The user guide has a keyboard workflow, and CI checks keyboard navigation and key ARIA/label issues in Chromium.

The audio and model generation paths are unchanged. This is not a claim of complete screen-reader compatibility; NVDA and VoiceOver use still needs direct testing. See [the accessibility review](../accessibility_review.md) for remaining work.
