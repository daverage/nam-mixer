## 3. Proposed input-gain anchors

Two anchor rules, so capture placement and gain mapping are never conflated:

- **fixed** (v3 rule): a capture at knob position N sits at input gain `-22 + 4(N-1)` dB.
- **response-distance** (revised mapping): anchors placed along the amp's measured response coordinate (arc length of the normalised tone+saturation+compression profile over ALL validated captures, level excluded), range -22 to +14 dB like v3, at least 4 dB between anchors so adjacent captures stay separable by level. Uses only measured captures; no NAM, no held-out DI.

## 4. Proposed 2x2 design per pilot amp (separates placement from mapping)

| Model | positions | anchor rule | answers |
|---|---|---|---|
| v3 C3 (existing, not retrained) | G1, G5, G10 | fixed | baseline; also evaluated with the revised mapping (playback only) = the mapping-only baseline from 4C |
| P-fixed | primary set | fixed | effect of capture PLACEMENT alone (vs v3 C3, same anchor rule) |
| P-resp | primary set | response-distance | effect of MAPPING on top of placement (vs P-fixed) |
| B-resp (optional) | budget k=3 set | response-distance | does an adaptively chosen 3 suffice? (vs v3 C3, and vs P-resp) |

Same architecture (A2), 60 epochs, same trainer and data recipe as v3 (467 s of official input + DI material at four level offsets). Two seeds each for P-fixed and P-resp so that seed noise can be compared with any claimed difference. Real training duration is recorded per model (v3 measured about 18-24 minutes per model when two to six run concurrently on this machine).

## 5. Evaluation protocol and acceptance criteria (proposed, to be frozen)

- **Independent material:** held-out DIs moderate_brit, clean_mayer, bass_rollin (never used in any fit); on the JCM800 the 9 genuine half-steps; on the Vibrolux there are no half-steps, so the untrained integer captures serve as untouched positions, with the caveat that they were used in the selection analysis (4D), so they are not fully independent.
- **Measures, reported separately:** tone EQ, HF>3 kHz, crest, sine THD, input/output slopes, dynamic range, output level (as in 4C), at DI levels -12/-6/0/+6 dB; level-matched ESR only as a supporting number.
- **Success (all must hold, versus v3 C3 with the fixed anchors, on held-out DIs and untouched positions):** (a) tone, HF and crest errors not worse by more than 10%; (b) input/output slope and dynamic-range errors each reduced by at least 15% for P-resp; (c) level error within 1.5 dB; (d) no group worse by more than 25% at any tested DI level; (e) the difference is larger than the seed-to-seed spread of the two seeds.
- **Interpretation rules:** an improvement that appears only with the revised mapping is a mapping result, not a placement result; a metric win without the listening set is a technical result, not an audible one; if the C3 budget candidate fails, report the failing behaviour and whether extra captures are a justified next step rather than adding them automatically.
- **Exported `.nam` requirement:** standard A2, playable in an ordinary player with input gain only; any improvement that needs extra DSP or metadata is reported separately.

## 6. Known risks to state before running

- Selection and mapping both use the same measured captures the models are later scored on; the held-out DIs and (JCM800) half-steps are the only fully independent material.
- 4C showed compression mismatch survives even the best mapping and looks like a limit of the level-driven design; expect P-resp to help that dimension only partly, and on the Vibrolux possibly at the cost of output level.
- The waveform-blend teacher has its own floor (about 1 dB of HF error even with five captures on the JCM800), which no choice of positions removes.
- One machine, one architecture, single-seed v3 baselines.
